# Shrimp Task Manager MCP：摘录说明

## 主要工具分组

- 规划 / 分析：`analyze_task`、`plan_task`、`reflect_task`、`process_thought`
- 任务系统：`split_tasks`、`list_tasks`、`get_task_detail`、`query_task`、`update_task`、`delete_task`、`clear_all_tasks`
- 执行指导：`execute_task`
- 研究追踪：`research_mode`
- 验证：`verify_task`

## 最适合的问题

- 复杂工程计划
- 带依赖关系的任务树
- 研究与执行跟踪

## 关键规则

- `execute_task` 只提供指导，不负责实现。
