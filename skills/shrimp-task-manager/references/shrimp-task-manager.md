# Shrimp Task Manager MCP: notes (condensed)

## Major tool groups

- Planning/analysis: `analyze_task`, `plan_task`, `reflect_task`, `process_thought`
- Task system: `split_tasks`, `list_tasks`, `get_task_detail`, `query_task`, `update_task`, `delete_task`, `clear_all_tasks`
- Execution guidance: `execute_task`
- Research tracking: `research_mode`
- Verification: `verify_task`

## Best-fit use cases

- Complex engineering plans
- Task trees with dependencies
- Research and execution tracking

## Key rule

- `execute_task` provides instructions, not implementation.
