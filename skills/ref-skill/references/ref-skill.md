# Ref MCP: notes (condensed)

## Tools

- `mcp__Ref__ref_search_documentation`
  - Search public docs by default
  - Include `ref_src=private` in the query if private docs should be searched

- `mcp__Ref__ref_read_url`
  - Read the exact URL returned by `ref_search_documentation`

## Best-fit use cases

- Official documentation lookup
- API reference pages
- Framework/library guides

## Key rule

- Search first, read second.
