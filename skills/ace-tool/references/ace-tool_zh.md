# Ace Tool MCP：摘录说明

这个参考文档用于确认 Ace Tool 的能力边界与查询方式。

## 可用工具

- `mcp__ace_tool__search_context`
  - 必填参数：
    - `project_root_path`：项目根目录绝对路径
    - `query`：用自然语言描述你想找的代码

## 最适合的问题

- “权限更新后缓存在哪里刷新？”
- “登录功能有哪些测试？”
- “消息消费者启动流程在哪？”
- “有没有类似实现可以参考？”

## 查询建议

- 先描述行为，再补关键词。
- 准备编辑时，把相关类 / 方法 / 属性一起写进一个查询。
- 只有在确实有帮助时，再补语言、模块或目录线索。

## 不适合的问题

- 精确标识符引用搜索
- 精确文件名查找
- 已知文件时的单文件阅读

## 推荐配合方式

1. 先做语义搜索。
2. 读返回的路径和片段。
3. 再切到直接读文件、精确搜索或编辑。
