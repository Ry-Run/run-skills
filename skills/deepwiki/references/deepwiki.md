# DeepWiki MCP: notes (condensed)

## Tool

- `mcp__mcp_deepwiki__deepwiki_fetch`
  - Key params:
    - `url`: repo URL, `owner/repo`, two-word owner repo, or library keyword
    - `maxDepth`: `0` for one site/page, `1` for broader fetch
    - `mode`, `verbose`: optional

## Best-fit use cases

- Open source repo overview
- Quick API or architecture summary
- Repo exploration before direct source reading

## Caveats

- DeepWiki content may lag behind the latest repository state.
- Verify critical details against primary sources.
