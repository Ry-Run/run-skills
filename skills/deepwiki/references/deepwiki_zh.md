# DeepWiki MCP：摘录说明

## 工具

- `mcp__mcp_deepwiki__deepwiki_fetch`
  - 关键参数：
    - `url`：仓库 URL、`owner/repo`、双词 owner repo 或库关键字
    - `maxDepth`：`0` 表示单页 / 单站点，`1` 表示更广一些
    - `mode`、`verbose`：可选

## 最适合的问题

- 开源仓库概览
- 快速了解 API 或架构
- 在直接读源码前先理解项目结构

## 注意事项

- DeepWiki 内容可能落后于仓库最新状态。
- 关键事实仍要回源验证。
