# Sequential Thinking MCP: notes (condensed)

## Tool

- `mcp__sequential_thinking__sequentialthinking`

## Key fields

- `thought`
- `thoughtNumber`
- `totalThoughts`
- `nextThoughtNeeded`
- Optional: `isRevision`, `revisesThought`, `branchFromThought`, `branchId`, `needsMoreThoughts`

## Best-fit use cases

- Hypothesis-driven debugging
- Design planning
- Revisable analysis

## Key rule

- Use it to structure reasoning, not to replace evidence collection.
